CSS Layouts

Técnicas que se utilizan para organizar y distribuir los elementos de una página web, como textos, imágenes, menús, botones y secciones. Su función principal es controlar la posición, el tamaño y la alineación de los elementos para que la página tenga una estructura ordenada y sea fácil de utilizar.

Animaciones

Efectos visuales que permiten cambiar gradualmente la apariencia o el movimiento de los elementos de una página web a lo largo del tiempo. Con ellas se pueden modificar propiedades como el color, el tamaño, la posición, la rotación y la transparencia de un elemento.

Sass

Lenguaje de hojas de estilo que amplía las posibilidades de CSS. Permite escribir estilos de una manera más organizada, reutilizar código y facilitar el mantenimiento de proyectos web. El código Sass se compila para generar CSS que el navegador puede interpretar.

¿Qué es CSS?

Es un lenguaje que se utiliza para darle diseño y apariencia a las páginas web creadas con HTML. Permite cambiar colores, tamaños de letra, fondos, márgenes, bordes, animaciones y la distribución de los elementos para conseguir una página atractiva y organizada, conocido como hojas de estilo en cascada, es un lenguaje que se utiliza para dar diseño y estilo a las páginas web. Permite cambiar colores, tamaños de letra, fondos, márgenes, bordes y la distribución de los elementos. Junto con HTML, ayuda a crear sitios web atractivos, organizados y adaptables a diferentes dispositivos.

¿Qué aprenderé en este curso?

En este curso aprenderás a utilizar CSS para diseñar y personalizar páginas web. Conocerás cómo cambiar colores, fuentes, tamaños, fondos, márgenes y bordes. También aprenderás a organizar los elementos de una página, crear diseños adaptables a diferentes dispositivos y utilizar herramientas como Flexbox y CSS Grid para lograr resultados modernos y profesionales.

¿Qué es CSS GRID?

CSS Grid es un sistema de diseño de CSS que permite organizar los elementos de una página web mediante filas y columnas. Facilita la creación de estructuras ordenadas, como galerías de imágenes, tarjetas, menús y diseños completos de sitios web. Además, permite controlar el espacio, la alineación y la posición de los elementos de manera flexible.
